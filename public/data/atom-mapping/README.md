# Atom Mapping Data

## Source

Generated by the `ModelSEED-reaction-mapping-setup` pipeline using **rxnmapper** (transformer-based atom-map prediction).

- **Primary source**: `benchmark-top100-rxnmapper` (100 reactions)
- **Fallback**: `final-rxnmapper-25` (25 reactions)
- **Mapper**: [rxnmapper](https://github.com/rxn4chemistry/rxnmapper) — IBM RXN atom-mapping model
- **Input**: ModelSEED Solr reactions API (`https://modelseed.org/solr/reactions_staging/select`)

## Regenerating

```bash
# From ModelSEED-reaction-mapping-setup repo root:
python3 scripts/export_atom_mapping_for_ui.py \
  --outputs-dir outputs \
  --output-dir outputs/ui-export

# Then copy to UI:
cp outputs/ui-export/atom_mapping.json \
  ../ModelSEED-UI/public/data/atom-mapping/atom_mapping.json
```

## Format

```json
{
  "generated_at": "<ISO-8601 UTC timestamp>",
  "source": "<run-name>",
  "mapper": "rxnmapper",
  "count": 100,
  "reactions": {
    "rxnXXXXX": {
      "mapped_smiles": "<atom-mapped reaction SMILES>",
      "confidence": 0.xx,
      "rdkit_ready": true
    }
  }
}
```

### mapped_smiles format

Uses standard reaction SMILES with atom-map indices:

```
[OH2:10].[O:1]([P:2](=[O:3])([O-:4])[OH:5])[P:7](=[O:6])([O-:8])[O-:9]>>[O:1]=[P:2]...
```

Each `:N` tag assigns a unique atom-map number. Atoms with the **same number on both sides** of the `>>` are the same atom tracked across the reaction.

## Notes

- Confidence scores are rxnmapper model confidences (0–1); higher = more certain
- `rdkit_ready: true` means the SMILES parses successfully with RDKit
- Atom-map numbers are used to assign consistent colors in the UI (same number → same color on both sides of the reaction)
